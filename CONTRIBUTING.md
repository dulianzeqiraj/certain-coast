# Contributing

* Open an issue before a large change; keep each pull request small and with tests (`run_tests` must pass in
  MATLAB and in GNU Octave).
* Code style: functions in the `+certaincoast` packages, a help block at the top of every function, core functions
  only (no toolbox), no syntax that GNU Octave cannot run (for example, no `arguments` blocks).
* No data files other than synthetic ones (see DATA_POLICY.md).
* By contributing you agree that your contribution is licensed under the Apache License 2.0.
