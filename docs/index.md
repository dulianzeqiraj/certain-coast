# CERTAIN-COAST documentation

* **Purpose.** Warnings for seawater intrusion, liquefaction and extreme water levels on a subsiding coast, each with a
  miss rate stated in advance and verified in operation.
* **Author.** Dulian Zeqiraj builds the coupled model and the alarm algorithm and maintains the code.
* **Language.** MATLAB, without toolboxes; every function also runs in GNU Octave. Type `help certaincoast` for the
  list of packages and `help certaincoast.alarms.conformalMargin` (for example) for one function.
* **Roadmap.** 0.1 alarms, warnings between samples, learned inland boundary, recharge from heads, variable-density
  flow and salt, goal-oriented network and recharge design (2026); coupled model with compaction, liquefaction and
  coastal water level, and certified fast copy (WP2); network design (WP4); decisions for the wellfields and twelve months of live
  operation (WP5); complete open release with a DOI (D6.1, Month 33).
